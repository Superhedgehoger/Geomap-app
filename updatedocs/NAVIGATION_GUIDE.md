# 功能入口与使用路径

## 第一级：先选择业务任务

| 入口     | 用来做什么                               |
| -------- | ---------------------------------------- |
| 经营总览 | 看门店规模、经营状态和区域分布           |
| 门店网络 | 搜索、筛选并定位门店                     |
| 历史复盘 | 新增经营记录、回放时间、对比两个时间点   |
| 选址分析 | 建立评分模型、比较候选点、记录推荐理由   |
| 经营数据 | 导入经营指标、查看趋势和区域排行         |
| 团队协作 | 私有工作区同步、评论、经营事项与成员管理 |

前四项是分析任务，后两项是数据与团队管理。没有启用的能力会明确标记「未启用」。顶部菜单和经营总览面板仍可分别隐藏。

## 第二级：地图工作台

「编辑地图」进入地图维护；「返回决策首页」返回经营总览。

| 分类 | 功能                                                      |
| ---- | --------------------------------------------------------- |
| 地图 | 图层面板、全部标签、聚合、缩放、地址搜索、坐标定位、底图  |
| 点位 | 绘图、手动添加、标记样式、坐标拾取；点击已有点位编辑属性  |
| 文件 | GeoJSON / Excel / CSV 位置导入、模板、导出、分享、单 HTML |
| 快照 | 保存地图版本、浏览及切换快照                              |
| 设置 | 代码编辑、弹出字段、传统名称提示、默认收起的数据清理      |

同一时间仅显示一个分类，避免长菜单堆叠。Tab 键进入分类栏，左右方向键切换，Home/End 到首尾分类。收起面板后保留同顺序快捷入口。

右下角「点位数据」提供点位表格和点位统计，不是经营指标看板。

## 容易混淆的概念

- **经营历史**：某家店何时开业、何时停业、当月经营数值等业务事实，进入「历史复盘」。
- **地图快照**：某次编辑后的地图版本，进入工作台「快照」。
- **位置文件**：包含坐标、名称、属性的地图数据，进入工作台「文件」。
- **经营指标**：关联门店和统计周期的营业额等数值，进入「经营数据」。
- **清空图层**：仅在「设置 → 清理地图数据」中显示，执行前应先导出备份，继续保留原确认步骤。

## 后续界面迭代原则

一个操作只有一个主要归属；快捷入口指向同一操作，不复制状态。常用功能优先显示，低频和危险操作逐层展开。名称使用业务动词，避免只有 A/B 等缩写。保留现有视觉风格和数据格式，不引入审批流程。

本次调整导航与入口，不改变选址评分、存储、导入导出或经营事项权限逻辑。
