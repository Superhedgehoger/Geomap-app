# Geomap v4.2 / v5.0 产品开发计划

> 2026-09-30 根据已确认的原计划整理。产品主线：发现问题 → 找到门店 → 安排动作 → 查看结果。

## v4.2：经营驾驶舱

管理层日常使用的重点是快速看到问题、找到依据并跟进结果。按下面顺序交付，每阶段保持主分支可部署。

| 版本          | 交付内容                                                                                                                      | 验收重点                                                             |
| ------------- | ----------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| v4.2.0-beta.1 | 门店 360°详情：基本资料、经营指标、历史事件、选址依据和决策记录集中查看                                                       | 从地图、门店列表和经营数据进入；资料缺失清楚可见；Full/Lite 能力一致 |
| v4.2.0-beta.2 | 异常中心和经营事项联动：营收下降、目标未达、连续下滑、数据缺失、逾期事项；事项编辑、责任人/截止日期筛选、批量更新、“我的事项” | 每个异常可追溯指标与周期，并能定位门店和相关事项                     |
| v4.2.0-beta.3 | 自定义经营驾驶舱与管理简报：选择首页 KPI、区域排序、保存管理视图；多门店趋势与目标对比；当前地图和筛选导出 PDF/图片           | 保存视图与导出内容一致，经营口径清楚                                 |
| v4.2.0        | 性能与移动端稳定：平板抽屉、移动只读查看、大量门店流畅筛选与回归                                                              | 日常管理场景稳定可用                                                 |

同步提供门店、月度经营和事件的数据导入模板，持续收拢重复入口，统一抽屉、筛选、日期与状态颜色。

## v5.0：企业经营空间决策平台

| 阶段           | 交付内容                                                   |
| -------------- | ---------------------------------------------------------- |
| v5.0.0-alpha.1 | PostgreSQL/PostGIS、统一业务对象、现有工作区迁移与备份     |
| v5.0.0-alpha.2 | Excel/CSV/API/数据库同步、字段映射、质量监控和指标口径中心 |
| v5.0.0-beta.1  | 完整选址模型、情景模拟、历史经营结果复盘与模型校准         |
| v5.0.0-beta.2  | 可解释的预测与风险提示、企业部署、SSO、组织与数据权限      |
| v5.0.0         | 数千门店和多年记录的性能、审计、备份恢复与完整回归         |

预测功能只作为可解释的参考信息；需要明确数据来源、假设、置信度与历史验证结果。产品流程不包含审批、驳回或撤回。
